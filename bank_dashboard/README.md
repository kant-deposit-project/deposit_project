# 정기예금 가입 예측 대시보드

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
`app.py`와 같은 폴더에 `bank-full.csv` 또는 `add_bank.csv`를 두면 자동으로 읽습니다.
(없으면 사이드바에서 업로드)

## 폴더 구조
```
bank_dashboard/
├── app.py
├── requirements.txt
├── .streamlit/config.toml
└── bank-full.csv  (또는 add_bank.csv)
```
